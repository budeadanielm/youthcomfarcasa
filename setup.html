Bază de date + Login pe GitHub Pages

GitHub Pages servește doar fișiere statice (HTML/JS). Nu poți rula MySQL/PHP pe GitHub. Soluția: Firebase (Auth + Firestore) – gratuit, cloud, accesibil de oriunde.

1. Creează proiect Firebase

  1. Intră pe console.firebase.google.com cu un cont Google.
  2. Add project → nume ex. farcasa-eyv → continuă (Analytics opțional).
  3. În proiect: ⚙️ Project settings → Your apps → iconița Web </> → înregistrează app (ex. farcasa-web).
  4. Copiază obiectul firebaseConfig (apiKey, authDomain, projectId, …).

2. Activează Login (Email/Password)

  1. Meniu Build → Authentication → Get started.
  2. Tab Sign-in method → Email/Password → Enable → Save.

3. Creează baza Firestore

  1. Build → Firestore Database → Create database.
  2. Alege locație (ex. europe-west) → Start in production mode.
  3. Tab Rules → lipește regulile de mai jos → Publish.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /meta/{doc} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /events/{id} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /feedbacks/{id} {
      allow read: if request.auth != null;
      allow create: if true;
      allow update, delete: if request.auth != null;
    }
    match /users/{uid} {
      allow read: if true;
      allow create: if request.auth != null;
      allow update: if request.auth != null;
      allow delete: if false;
    }
    match /channels/{id} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /channels/{id}/messages/{mid} {
      allow read: if true;
      allow create: if request.auth != null;
      allow update, delete: if request.auth != null;
    }
    match /joinRequests/{id} {
      allow read: if request.auth != null;
      allow create: if request.auth != null;
      allow update: if request.auth != null;
      allow delete: if request.auth != null;
    }
  }
}

Public: citire indicatori + evenimente. Oricine poate trimite feedback. Doar userii logați modifică datele admin.

4. Completează config în site

  1. Deschide fișierul js/firebase-config.js.
  2. Lipește valorile din Firebase (apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId).
  3. În ADMIN_EMAILS pune emailurile care au acces la Dashboard, ex. 'maria@gmail.com'.
  4. Salvează și reîncarcă site-ul. Badge-ul de pe Login ar trebui să arate Cloud DB.

5. Publică pe GitHub Pages

  1. Creează un repo GitHub (public), urcă tot folderul farcasa-eyv (conținutul, cu index.html la rădăcină).
  2. Settings → Pages → Source: Deploy from a branch → branch main / folder / → Save.
  3. În 1–2 minute site-ul e la https://UTILIZATOR.github.io/NUME-REPO/.
  4. În Firebase → Authentication → Settings → Authorized domains → Add domain: UTILIZATOR.github.io.

Ce se salvează în cloud

  • meta/indicators – cei 10 indicatori
  • events – calendar
  • feedbacks – feedback-uri
  • users – profil la sign up

Până configurezi Firebase, totul merge local (localStorage) cu admin / farcasa2027.

După setup: login.html → Sign up cu emailul din ADMIN_EMAILS → Dashboard.
